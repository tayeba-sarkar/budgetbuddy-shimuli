# BudgetBuddy - Personal Finance Tracker 💰

Live Demo: https://budgetbuddy-shimuli.vercel.app (Vercel e deploy er por link update korbo)

A simple and beautiful personal finance tracker built with React for Bangladeshi users.

### ✨ Features
- Add Income & Expense in BDT
- Real-time Balance Calculation
- Recent Transactions List
- LocalStorage Support
- Responsive Design with Tailwind CSS

### 🛠️ Tech Stack
- React + Vite
- Tailwind CSS
- JavaScript (ES6+)
- LocalStorage
